# Habibat Oyeleye — Live Projects Portfolio

A responsive portfolio for showcasing live websites, automation scenarios, and integrations. Includes Projects, About, and Contact pages, plus a user-controlled light/dark theme.

## Included pages
- `index.html` — project gallery with category filters and links to real destinations.
- `about.html` — About page focused on websites, workflow automation, and integrations.
- `contact.html` — contact form and direct email/LinkedIn links.
- `style.css` — responsive blue/cyan/violet design with dark and light themes.
- `script.js` — theme toggle, mobile navigation, project filters, and footer year.

## Publish with GitHub Pages
1. Create or open a public repository named `Live-Projects-Lab` in the `Oyinronke` GitHub account.
2. Upload these files to the repository root and commit the changes.
3. Go to **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.
5. When deployment finishes, the site should be available at `https://oyinronke.github.io/Live-Projects-Lab/`.

## Contact form setup
The form uses FormSubmit and sends submissions to `oyinronke15@gmail.com`. On the first submission, FormSubmit may send an activation email to verify the recipient. The form should not be described as fully active until that email verification is completed and a test submission succeeds. Direct email and LinkedIn links are also available as alternatives.
